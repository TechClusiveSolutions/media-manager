# Mediman User Guide: Keyboard Commands

Every major action in Mediman can be performed from the keyboard. Nothing requires a mouse. This guide lists the default keyboard command for each action, organized by where you're working in the app.

If you use a screen reader, note that the commands for feed item actions (Reply, Boost, Favorite, Quote) use the `Ctrl+Alt` combination rather than a single letter. This is intentional: single unmodified letters are used by JAWS and NVDA for their own quick-navigation keys, so Mediman avoids conflicting with those.

All of these commands can be changed. See "Customizing Keyboard Commands" at the end of this guide.

## Global Commands

These work anywhere in the main Mediman window.

* `Ctrl+N` — Start a new post
* `Ctrl+Shift+N` — Start a new post with AI drafting help
* `Ctrl+,` — Open Settings
* `Ctrl+Shift+A` — Add a new account
* `Ctrl+M` — Open Manage Accounts
* `Ctrl+Shift+R` — Reconnect the current account (when it needs reauthentication)
* `Ctrl+Shift+U` — Switch to the Unified feed view
* `Ctrl+D` — Open your Direct Messages
* `Ctrl+Shift+L` — Review your Autonomous Post Record
* `F1` — Open the Help/User Guide
* `Ctrl+Q` (or `Alt+F4`) — Exit Mediman

## Moving Around the Main Window

* `Ctrl+Tab` / `Ctrl+Shift+Tab` — Move forward/backward between open items, such as feed views and open drafts
* Arrow keys and `Tab` — Move through the side navigation tree and lists, the same way you'd navigate any tree or list control
* `Ctrl+F` — Jump to the search box, when you're in Settings or the Notifications list

## Working with a Feed Item

Once you've moved keyboard focus onto a post in a feed, these commands act on that post:

* `Ctrl+Alt+R` — Reply
* `Ctrl+Alt+B` — Boost/repost
* `Ctrl+Alt+F` — Favorite/like
* `Ctrl+Alt+Q` — Quote/share
* `Ctrl+O` — Open the full post/thread detail

## Composing a Post

These work while a compose window has focus:

* `Ctrl+Enter` — Send the post
* `Ctrl+W` — Close this draft
* `Ctrl+Shift+P` — Add another platform to this draft
* `Ctrl+Shift+G` — Get AI-generated prompt suggestions
* `Alt+1` through `Alt+9` — Jump directly to the 1st through 9th platform section in this draft

## Customizing Keyboard Commands

Every command listed above can be reassigned to a different key combination.

1. Open Settings (`Ctrl+,`).
2. Go to Accessibility, then Keyboard Commands.
3. Find the command you want to change and enter a new key combination.

If you choose a key combination that's already assigned to something else, Mediman will tell you which command currently uses it and ask you to confirm before reassigning it — the other command will become unassigned, so you may want to give it a new combination afterward.

You can reset a single command back to its default from its own entry in this list, or use "Restore All Defaults" to reset every command at once.
