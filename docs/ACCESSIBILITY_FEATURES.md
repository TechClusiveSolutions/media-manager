# Mediman User Guide: Accessibility Features

Mediman is designed to be usable by everyone, including people who are blind, have low vision, are deaf or hard of hearing, are dyslexic, or have other cognitive or physical disabilities. This guide describes the accessibility features available and where to find them.

For the full list of keyboard commands, see `KEYBOARD_SHORTCUTS.md` in this same folder.

## Keyboard Access

Every action in Mediman — posting, replying, boosting, managing accounts, adjusting settings — can be done entirely from the keyboard. Nothing requires a mouse. All keyboard commands can be reassigned to whatever combination works best for you, from Settings → Accessibility → Keyboard Commands.

## Screen Readers

Mediman is built to work with screen readers, including JAWS, NVDA, VoiceOver, and Orca. Every screen and control is labeled so a screen reader announces what it is and what it does. When something on screen changes on its own — for example, an account needing you to reconnect — Mediman announces that change so you don't have to go looking for it.

By default, Mediman does not announce every new post arriving in a busy feed, since that could be overwhelming. If you'd like new-post announcements, you can turn them on in Settings → Notifications.

Images in your feed that come with a description from the original platform will have that description read to you. If an image has no description, Mediman tells you that plainly rather than skipping it silently, and offers a button to generate a description using AI if you'd like one — this only happens when you ask for it, never automatically.

## Low Vision

* **Themes**: Mediman follows your operating system's light/dark/high-contrast setting automatically, or you can choose a theme yourself in Settings → Accessibility.
* **Text and UI size**: a size slider in Settings → Accessibility lets you make all text and controls larger or smaller, separate from your operating system's own zoom or scaling setting.
* **Not just color**: status indicators (like an account needing reconnection) and warnings always include an icon or text label, never color alone, so they're clear even if you have difficulty distinguishing colors.

## Deaf and Hard of Hearing

* Captions provided by the original platform on video and audio posts are shown when available.
* Every notification that makes a sound also has a visual equivalent — nothing in Mediman depends on hearing an alert to know it happened.
* If you turn off system sound notifications, the in-app notification list still shows you everything.

## Dyslexia

* A dyslexia-friendly font option is available in Settings → Accessibility and applies everywhere in the app — menus, buttons, feeds, and compose windows.
* Line spacing and letter spacing can also be adjusted from the same settings pane.
* Error messages and confirmations in Mediman are written in plain language: what happened, and what you can do about it.
* Nothing in Mediman is timed. You will never be rushed to respond to something before it disappears or expires.

## Physical and Motor

* No feature requires a mouse, precise clicking, or dragging and dropping.
* Keyboard commands never require pressing more than two modifier keys at once, and never require pressing keys in a fast sequence.
* Buttons you click, like feed actions and toolbar controls, are sized to be easy to hit even without precise pointer control.

## Where to Find These Settings

Most of the features described here live in one place: **Settings → Accessibility**. If you're not sure whether a setting exists for something you need, check there first, or open an issue against the project if you find something that isn't accessible.
