# Mediman Documentation

Mediman is a cross-platform, accessibility-first desktop application for managing multiple social media accounts — Mastodon, X (Twitter), and Facebook — from a single interface. See the repository [`README.md`](../README.md) for a full description, project status, and accessibility commitments.

## Guides

* [User Guide: Setup](USER_GUIDE.md) — installing Mediman and connecting your first Mastodon account.

More sections (feeds, composing and cross-posting, direct messages, notifications, AI-assisted drafting) will be added here as those features ship.
